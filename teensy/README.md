# Teensy 4.1 firmware

Bare-metal real-time side of BARC: selector, safety manager, state estimator, locomotion controller, motor CAN, IMU, iBUS receiver, e-stop input, Jetson serial link.

PlatformIO environments (to be defined in platformio.ini): teensy41 for the robot, native for host unit tests of the safety and control logic.
